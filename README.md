# C Mastery X - Summit 1.0

## CSBS SkillBridge

**C Mastery X - Summit 1.0** is a 10-day online C programming skill
development programme organized by the **Department of Computer Science
and Business Systems, Ramco Institute of Technology**.

> **Programme Theme:** Building C Programming Skills: Logic, Problem
> Solving, and Interview-Oriented Coding for Industry Readiness.

This repository contains the C programs practiced and completed as part
of the programme.

## Programme Highlights

-   C Programming Fundamentals
-   Logical Thinking & Problem Solving
-   Interview-Oriented Coding Practice
-   Expert-Led Sessions
-   Dynamic Memory Management
-   Arrays, Functions, Loops, Conditional Statements, Pointers,
    Structures and more

## Repository Programs

### Set 1 - Dynamic Memory Allocation

1.  **Largest and Smallest using `calloc()`**
    -   Dynamically allocates memory for `n` integers.
    -   Reads array elements.
    -   Finds the largest and smallest elements.
2.  **Array Resizing using `malloc()` and `realloc()`**
    -   Creates an integer array using `malloc()`.
    -   Increases its size using `realloc()`.
    -   Accepts additional elements and displays the complete array.
3.  **Sum and Average using `malloc()`**
    -   Dynamically allocates memory for integers.
    -   Calculates the sum and average of the elements.

### Set 2 - Number and Array Problems

1.  **Strong Number**
    -   Checks whether a given number is a Strong Number.
    -   Example: `145 = 1! + 4! + 5!`.
2.  **Second Largest Element**
    -   Finds the second-largest distinct element in an array.
    -   Does not sort the array.
3.  **Palindrome Number and Reverse**
    -   Reverses a number using loops.
    -   Checks whether the number is a palindrome.

### Set 3 - Conditional Statements, Loops and Functions

1.  **Electricity Bill Calculation**
    -   Calculates an electricity bill based on unit consumption and
        tariff slabs.
    -   Uses conditional statements.
2.  **Armstrong Numbers**
    -   Displays all Armstrong numbers from `1` up to a user-specified
        limit.
    -   Uses loops and conditional statements.
3.  **Menu-Driven Calculator**
    -   Uses separate functions for:
        -   Addition
        -   Subtraction
        -   Multiplication
        -   Division
        -   Modulus
    -   Performs the operation selected by the user.
